## Isi Tugas JavaScript

### Langkah 1 --- Perbaikan Kode

Memperbaiki kesalahan seperti: - deklarasi variabel ganda - penulisan
nama variabel - penggunaan `console.log` - tipe data tahun berdiri -
penggunaan `const` - operator perkalian `*` - index array

### Langkah 2 --- Object dan Array

Membuat object `usaha` yang berisi: - nama usaha - pemilik - akun -
kota - tahun berdiri - status buka - nomor WhatsApp - website

Membuat daftar produk menggunakan array object.

### Langkah 3 --- Perhitungan

Program menghitung: - harga produk setelah pajak 11% - harga termurah -
harga termahal - usia usaha - format harga Rupiah

### Langkah 4 --- Tipe Data

Menguji penggunaan `typeof` dan operator JavaScript, termasuk: -
number - string - boolean - undefined - null - object - operator `+` -
operator `*`

### Langkah 5 --- Modifikasi

Menambahkan: - produk baru: Keripik Sagu Papua - akun Instagram -
perhitungan total harga produk

### Bonus

Membandingkan `var` dan `let`, termasuk: - `var` dapat diakses di luar
block `if` - `let` hanya berlaku di dalam block - `var` dapat
dideklarasikan ulang - `let` tidak dapat dideklarasikan ulang

## Cara Menjalankan

1.  Buka folder project di Visual Studio Code.
2.  Pastikan `index.html` memanggil file JavaScript.
3.  Buka `index.html` menggunakan Live Server.
4.  Buka **Inspect → Console** pada browser.
5.  Jalankan dan periksa hasil JavaScript.

## Catatan Favicon
